# AI Knowledge Base 🤖

An AI-powered knowledge base platform built to organize, store, and retrieve information efficiently.

## 🚀 Features

* Create and manage knowledge
* Search and retrieve information
* Responsive and user-friendly interface
* RESTful API integration
* MongoDB-based data storage

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript, HTML, CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB

## 📂 Project Structure

```text
AI-Knowledge-Base/
├── frontend/
└── backend/
```

## ⚙️ Installation

```bash
git clone https://github.com/your-username/ai-knowledge-base.git
cd ai-knowledge-base
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

This project was developed to gain practical experience in **full-stack web development**, REST APIs, database management, and building AI-oriented applications.
